# Altyazılı TV kanal listeleri

Altyazılı TV'nin çevirebildiği 10 dildeki ücretsiz kanallar; her kanal "Dil / Tür" grubunda
(ör. "İngilizce / Haber"). Veriler [iptv-org](https://github.com/iptv-org/iptv) deposundan
her pazartesi otomatik yenilenir. Yetişkin, kapanmış, telif nedeniyle engellenmiş ve konuşma
içermeyen (müzik, alışveriş) kanallar çıkarılmıştır.
